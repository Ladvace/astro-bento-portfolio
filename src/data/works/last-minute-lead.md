## Overview

Last Minute Lead is a platform where businesses buy leads. I built it as a freelance project, aiming for a flow that feels like shopping online: browse, pick, check out.

## Stack

Next.js on the frontend with tRPC for end-to-end typed APIs, and Drizzle ORM on a MySQL database.
